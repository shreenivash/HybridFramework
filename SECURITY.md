# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 1.0.0-SNAPSHOT | Yes |

## Reporting a vulnerability

Do **not** open a public issue for security problems.

Use [GitHub Security Advisories](https://github.com/shreenivash/HybridFramework/security/advisories/new) on this repository.

Please include:

- Affected module (`core`, `web`, `mobile`, `api`, `testng-engine`)
- Impact and reproduction steps
- Any suggested fix

We will acknowledge the report and work on a fix before any public disclosure.
